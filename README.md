这是大部分绿云测评没讲透、但直接影响你花钱的部分。绿云全球有近 30 个机房，但同一个套餐在不同位置的配置并不一致，差异主要有三处。

**第二，热门机房的 CPU 和硬盘更好，但常年缺货。** EPYC Rome/Milan 处理器配 NVMe 的节点（纽约、洛杉矶、阿姆斯特丹、凤凰城等）性能明显好于老的 E5v4 至强配 SSD 的节点（芝加哥、堪萨斯城、杰克逊维尔等）。写本文时，Budget KVM Sale 有货的位置主要是芝加哥 DC2、杰克逊维尔和堪萨斯城，多数 NVMe 节点显示售罄。绿云的补货没有固定时间表，抢热门机房要么蹲它的 Telegram 和 Discord 通知，要么接受老机型。

**第三，个别机房的 IPv6 有缩水。** 堪萨斯城和香港 DC2 的 IPv6 是 /112，其他机房是标准的 /64。需要大量 IPv6 地址的用户（比如跑代理池）要注意这个细节。
